# BuildSweep

BuildSweep is a small macOS utility built with Swift and SwiftUI for reclaiming disk space used by regenerable development files.

Working across multiple repositories, coding sessions, and AI-assisted projects can quickly leave behind Rust `target` directories, Swift `.build` directories, Xcode DerivedData, debug output, and other generated build artifacts. Even a handful of inactive projects can consume tens of gigabytes.

BuildSweep is intended to find these build artifacts, show how much space each one uses, and let you choose which items to move to Trash. Nothing is permanently deleted by the app, and the files can be regenerated by their original build tools when you return to a project.

The planned interface is a lightweight native macOS menu bar utility, making it quick to inspect and reclaim development space without interrupting your workflow.

BuildSweep is currently in early development and is being built one feature at a time as a practical way for me learn Swift, SwiftUI, and native macOS development better.
